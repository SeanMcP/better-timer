# Better Timer

⏲️ A mobile-friendly timer that is better than Android's clock app

## Features

- PWA, works offline
- Full screen
- Keeps screen on
- Toggle between countdown and visual timer
- Quick presets: 1, 2, 3, 5, 10 minutes
- Pause, reset, cancel
- Classic Casio alarm
- Volume: loud, quiet, silent
- Remembers your settings
- Shareable links
- Dead simple

## URL params

- `t`: time in seconds
- `m`: `countdown` or `visual`
- `v`: `loud`, `quiet`, or `silent`

Example: `?t=300&m=visual&v=quiet`
